# Research logs

Dated, signed notes of what was **learned or built** — not dump folders and not “receipts.”

## Title convention

| Do | Don’t |
|----|--------|
| `# Force-cap gradient — collapse quality across 0 → 1.0` | `# Receipt: Force Cap Gradient` |
| `# Memory coupling validation — residual wills across reloads` | `# Research Entry: …` |
| Filename: `YYYY-MM-DD_snake_or_kebab_topic.md` | `receipt_YYYYMMDD_topic.md` |

Raw smoke tables and auto stubs can still live under `logs/**/RECEIPT.md` if scripts emit them. **Human research notes** use real titles.

Template: [`TEMPLATE.md`](TEMPLATE.md) · authorship: [`AUTHORSHIP.md`](AUTHORSHIP.md)
