## Phase 1 — TCT shared crate (the first real merge commit)

**Why first:** hydro `src/tct.rs` (594 lines) and niodoo-live `niodoo/src/tct_splat_lite.rs`
(424 lines) are two independent implementations of the same `TCT1` binary format. Silent
drift here breaks death→reload someday. One implementation, two users.

**Steps** (each its own commit, on a branch — `git checkout -b tct-crate`):

1. Create `crates/niodoo-tct/` in this repo: `cargo new --lib crates/niodoo-tct`,
   add to workspace `members` in `Cargo.toml`.
2. Move `src/tct.rs` content into the crate. Keep the public surface identical;
   hydro re-imports via `use niodoo_tct::...`. Build until green:
   `CUDARC_CUDA_VERSION=12000 cargo build --release --bin hydrodynamic-swarm`.
3. Smoke on hydro side: export→import round trip
   (`--export-tct` / `--clear-memory --import-tct`), then
   `./scripts/continuity_multibridge.sh` — need **PASS_RETURN** unchanged.
4. Point niodoo-live at the crate (path dependency), port `tct_splat_lite.rs`
   callers to it. Smoke: `niodoo-live/scripts/gemma_tct_smoke.sh` mode 2 —
   need **SPEECH PASS** + KPI **WARM** on Friendship (nearest~184, pot~0.013 ballpark).
5. Write the research log entry, then merge the branch.

**Acceptance:** continuity_selftest passes, A→B→A PASS_RETURN, live smoke WARM+SPEECH PASS.
**[SPEND]** only if a Rust borrow/linker error eats more than ~1 hour — that's the one
place a Claude question is worth budget. Everything else here is mechanical.
