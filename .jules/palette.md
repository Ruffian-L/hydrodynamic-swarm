## 2024-03-15 - SplatLens Accessibility Improvements
**Learning:** Adding accessibility and keyboard navigation features (such as `for` attributes on `<label>` tags, `aria-live="polite"` on dynamically changing elements, replacing invalid `<label>` tags with `<span>`, and configuring `:focus-visible` styling) are essential. It improves the UX for users navigating with keyboards or using screen readers without changing core layout or visual aesthetics for mouse users.
**Action:** When implementing or modifying UI, always ensure that all `<label>`s correctly use `for` linked to inputs. For text labels meant for elements other than inputs (like grouped buttons), use styled `<span>`s with proper ARIA groupings. Apply `aria-live` attributes to dynamically updated states and build in `:focus-visible` outlines by default.
