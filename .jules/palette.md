## 2024-05-18 - Accessible Canvas Viewer HUDs
**Learning:** Custom HUDs in interactive visualizations (like HTML5 Canvas apps) often miss critical accessibility hooks for UI controls. Elements with dynamically updating numeric values (step counts, percentage scales) aren't announced to screen readers. Label tags are often present visually but improperly linked, which breaks the tap targets. Also, the lack of focus rings makes navigating canvas apps with a keyboard extremely difficult.
**Action:** Enforced `for` attribute linkages on all input labels for larger tap targets and screen reader context. Added `aria-live="polite"` to spans/divs acting as dynamic numeric displays so their updates are announced natively. Added custom `:focus-visible` outlines matching the primary accent color (`#40E0D0`) to interactive components.
